《新经济危机开始前夜——人类社会架构更新》
社会上的商品越多，社会上的真实商品越少。给你一块钱是吝啬，给你一万块钱你会感恩，给你一千万的时候，你需要的是拒绝。
******摘要
新的经济危机还没有开始，但是即将开始。经济学家固执的认为是2027-2028，但是看看当前的社会，人们远远没有经历到全球性的阵痛，没有经历新的挤兑危机。如果说1929年全球大萧条来自于股市，股市才是真正的银行，那么下一轮危机就不会简单重复，相似的路径，下一轮经济危机爆发的现象应该是你手里有钱但是买不到任何商品了。
******效率提升之下————人类忽视了
在开始之前，想了很多内容，但是问题出现在哪里？看了Ai的总结，看了诺贝尔经济学家的分析，所有人都在用现有的经济学框架分析，所有人都在担心危机，都在焦虑。一种完全悖论的复杂状态在凝聚，但是忽视最重要的东西，那就是效率。
在2000互联网去泡沫之后，全球的生产力和效率得益于中美两个大国的努力，爆发了巨大的增量，美国提供前沿的智力加持，中国用全球最好的最有纪律的工人提供了最高效率的产出比，全球都认为中国的仓库里有的是东西，就是卖不出去。可是，当我深入工厂一线我才发现，我们的工厂里没有任何东西，我们的生产效率极度低下，一旦遇到全球性的商品兑付危机，仓库会被瞬间清空，缺口需要接近十年才能补的上。
*****全民销售的撮合交易模型
在此借用一下股市交易中的撮合交易，其实人类就是物理世界中最大的撮合交易节点。不同于股市的是，股市有了订单有了高低价差，撮合交易才能有效，才能攫取利润。如果价差过低或者取消过快，撮合交易自动失效，因为在股市当中不会出现任何一端的不平衡。但是在人类市场，这两端正在失衡。
****人与人之间的撮合交易，借用算法的撮合交易
我所在的公司是一个电梯配件的代工厂家，每天我都在看着公司的内勤在疯狂的协调采购方与工厂出货。这其中有个很关键的问题，销售端被无限放大了，但是工厂的商品还处在虚空之中。我们要面对的是数个购买方。但是工厂生产面临库存压力面临工人工资升值压力，面临固定资产或贬值或升值的波动压力等等。所以老板希望尽可能多的人去协助销售公司产品，尽可能多的用目前的销售平台上架自己的商品。但是这其中有一个明确的兑付延迟，那就是物流。我们在商场买东西，是现款现货现结算。我居住在杭州，中国电商贸易最发达的地方，网上下单，一般来说24小时内就能收到商品。这其中就出现了第一个关键变量，钱是预付的，商品是后付的。
我们用手机壳举个例子。我曾经在一个手机壳厂商兼职过一天。这个手机壳厂商直接从上游进货白膜手机壳，然后在自己工厂印刷图案。这里有个很大的忽视点，这一切几乎都是全自动的：因为互联网的存在因为自动化算法或者API接口的存在。在淘宝上，终端客户想买iPhone13pro的玉桂狗手机壳，客户选好之后付款，淘宝自动生成编辑好的命令传递给工厂，工厂确认，甚至不需要确认，因为单个产品的损失足够微小，甚至这些只要不是残次品完全可以让工厂内部的人当成残余价值在闲鱼上销售出去。那么第一个问题就来了，同样一个商品，在不同的渠道存在了第一次商品价值剥落。作为终端客户的我们看到拼多多和淘宝有同样的商品为啥会有价格差异，人们本能的就会选择价格便宜的。当然不可否认有人会为了质量好买单，所以会选择两个，但是这里有个很有意思的环节，退货保。所以终端用户不介意用很小的几毛钱退掉。这样就会有一个致命的传导，退货给代理，代理的选择极其有限，选择一直接价格削减二次销售。市场上出现了价格落差，总有人选择便宜的产品，人与人之间就会发现同样的手机为什么他的那么便宜，质量相差还不大。选择二，代理商退货给工厂，工厂发现生产的东西之后卖不出去，库存积压，本能的要削减生产量，积压的商品要么看着一文不值，要么降价销售。如果源头降价销售，源头还在终端客户前一站布置销售节点（无论厂商是否愿意，工厂内部总有人会把积压的商品给卖出去套利）。在价格差之间一个新的节点出现必然引起价格落差的拉平。但是对于生产方和终端客户来说都是致命的。
***终端客户
就拿我而言，我作为一个终端客户，我看到淘宝，拼多多，看到闲鱼京东有同一个产品，或者基于同一个白膜产品的不同图案或者不同包装的产品，我自然而然会选择便宜的产品，但是在多次选择期间，我的购买次数和退货次数越来越多的时候，那么造成的贬值效应就会越来越大。人的大脑——这个全球最大的自动化撮合交易工具会自动识别并计算最大的套利决策。现代的物流效率，现代的生产效率和高雅的生活正在全面侵蚀人的认知能力。
***工厂
真正的生产方看到的是退货率越来越高，看到的是积压的商品是越来越多，看到的是社会上相同的或者相似的产品越来越多，价格越来越便宜，就本能的降价。当有一天，支付的工资，积压的库存彻底消耗掉所有流动性，这个工厂就倒闭了，但是该公司的商品被作为贷款偿还资产，会被直接丢进市场上消化，这就是最恶性的螺旋死亡。商品的流转效率越高，价值削减的越多，生产的效率越低。
我目前还没做乘数计算，我一个人没那么多精力去计算中国目前的真实的生产力有多少。市场上的真实需求是在缓慢上升的，但是社会上的真实生产力是在极大的下降的，这一真实的生产指数还在被大幅压缩。有人会觉得，但是身边还是有很多工厂活着啊？深入那些工厂，你会发现，他们的真实产能，已经下降到了一个极低的水平。目前的工厂逻辑是保持一个极低的生产力，假设一个工厂有30个人在真实生产，那么他们的每月基本开销就是将近10万元，所以他们大约需要生产货值50万的产品。一年的真实生产力只有500——600万之间（这个是估算，后面会在后续版本精细化模型）。其次就是，因为工人足够廉价，工资还是后付费，所以这个月的十万元支出在下个月就已经不是10万元了，就会自然而然减少，这个货币价值概念不做过多解释。
****核爆的原点
因为这个是初稿，我不确定核爆的原点来自哪里，这个环节没有思考完善，但是一定不会来自股市，因为全球对大宗原材料的监控已经很完善了，原材料的价格上涨就是经济危机开始的前置信号。因为新一轮的经济危机爆发是全球人民的需求大爆发，而不是需求衰减。相应的，衣服会短缺，价格会上涨，人们慢慢的发现居然买不到衣服了，其次就是锅碗瓢盆（这个路径没有深入优化以后再说）但是在时间尺度上会变得更加漫长，这个放大的因素就来自全球极高的物流效率。痛感因为物流效率的提高，变得更弱更缓慢更漫长，但是癌症不就是这样的表现吗？等他真的显示出来威力的时候，人类这个集合体有多大的能量度过这次危机呢？美国经济大萧条是一场重感冒，需要以毒攻毒的医治，但是新的经济危机是癌症，当人们发现他的时候，治愈癌症的方式就不是以毒攻毒了，而是需要切除癌症组织了。
基于上述的推测与分析，我觉得这个经济的高烧原点应该是高端生产力以及其产出。表现形式应该是Ai行业变现困难，但是建的芯片工厂，还未投产的内存工厂彻底有了生产力之后。人们会发现，内存出奇的便宜了，Ai惊人般的赚钱了，但是别忘了，比价，退货这个魔咒。大厂在赚钱之后也会退货，大量的退货就会导致工厂去产能（中国正在做的事），然后市场价格会被进一步压缩。社会上会充斥越来越多的显卡，芯片，内存条等等。然后因为社会新质生产力的爆发，人们可以用更短的时间挣到更多的钱了。有了钱就需要消费了，需要的是中端消费——这个时候高端的芯片、内存条、手机、电脑等等已经彻底沦为中端享受型消费品了，但是人们惊奇的发现社会的上的内存条消失了，芯片消失了，手机也消失了。然后过剩的消费欲望以及欲求不得的产品购买需求伴随着恐慌蔓延，当恐慌彻底碾压一切的时候，这个癌症将会彻底暴露在全球人的面前。
在写这些的时候，我感觉自己就是胡思乱想，但是covid疫情算是一场小规模预演。上海就是一次缩小规模的新癌症式经济危机演习。上海，今本就是中国最先进的智力生产力聚集区。类比全球来看，这里就是美国。2022年春季封城的时候，人们根据政策就准备了五天的物资，然后觉得封城结束，一切会照旧。但是奥密克戎隐匿一起快速的传播迅速撕裂了政策空间。这时候就不是上海政府想要解封就能解封了，整个上海彻底陷入了死循环。
2018-2020是特朗普第一次关税战，全球物流和贸易因为政策主导的恐慌情绪蔓延爆发了前所未有的能量，各个工厂因为这个政策不仅没亏钱反而赚了很多钱。物流运输行业因为巨量的需求价格持续攀升，效率也在大幅度提高。这基本就是新冠的开始，一个新的病毒开始传播了，人类会有有点痛苦，但是之前积累的物资足够大家继续安逸的生活，而且不用干活，干活的还在赚超高的利润大家都乐此不疲。然后是拜登的小院高墙策略，致命德尔塔毒株变体，但是因为致命，所以传播能力不强很快就下去了。现在已经很接近奥密克戎变体了。特朗普重新上台，再来了一次贸易战，大家都以为是最初的毒株，都以为是短暂的封锁。但是隐匿的奥密克戎变体已经开始传播了，因为人体这个机器过于庞大，身处于这个身体内部的人感知完全不到整体的变化。当下一次中美的运输路线被封锁，人们会惊奇的发现，越是想解封越不能解封的死亡螺旋。
用现实社会做对比，就是美国因为Ai行业的彻底爆发，完全迎来了新的辉煌，人们的工作时间大幅减少，但是高端产业的生产力严重过剩。这就需要把产品卖给中国，但是卖给中国意味着先进技术外泄。全美国社会都不允许。这里要补充一点，美国的总统选举是共识机制，所以特朗普的政策基本就代表着美国的民众的意志，如果下一个继续这种政策的总统上台，只要稍微一把火就能彻底点燃这个新的经济危机路径。美国依靠智力产出，结果发现离开工厂离开运输产不出来任何东西了。中国有丰富的食物，有丰富的米面粮油，有衣服有各种中端制造业产出的手机电脑锅碗瓢本沙发板凳，但是再也没有能力运输进美国这个城市了。
那么对于中国呢！
中国生产的商品因为政策运不进去，在外面的空转中彻底腐烂沦为垃圾，美国因为积累的商品快速被消耗，人们在期待与恐慌中等待，当恐慌彻底压过期待，一切的兑付危机就爆发了，但是外面的工厂已经消失了，中国就算想生产也找不到厂家了，有商品也找不到运输商了。漫长的物资匮乏的黑夜就会来到。
